# Table - behaviour_summaries

**Schema:** AI

**Version:** 1.0

**Status:** DRAFT

---

# Purpose

The `behaviour_summaries` table stores AI-generated behavioural insights for a Student Snapshot.

Behaviour Summaries are generated by analyzing chatbot conversations and behavioural evidence.

They provide interpretable information for mentors while supporting the Prediction Engine.

Behaviour Summaries are immutable.

---

# Template Type

Historical Entity

# Business Rules

- Every Behaviour Summary belongs to exactly one Student Snapshot.
- Behaviour Summaries are generated by AI.
- Behaviour Summaries are immutable.
- Every new Student Snapshot generates a new Behaviour Summary.
- Behaviour Summaries never modify chatbot conversations.

# Business Constraints

- One Behaviour Summary belongs to one Student Snapshot.
- Behaviour Summaries are generated only after feature engineering.
- Behaviour Summaries are immutable.
- Confidence Score must be between 0 and 100.
- AI-generated summaries are never manually edited.

# Notes

Behaviour Summaries provide human-readable behavioural insights.

Examples

```
The student has shown reduced engagement over the last three academic imports.

Recent conversations indicate increased academic stress before assessments.

Attendance remains stable, but behavioural patterns suggest declining motivation.
```

Behaviour Summaries are intended for mentors and counselors.

They do not replace chatbot conversations.

Original chatbot conversations remain stored in the Behaviour Schema.
