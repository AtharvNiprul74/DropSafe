# Table - predictions

**Schema:** AI

**Version:** 1.0

**Status:** DRAFT

---

# Purpose

The `predictions` table stores the latest AI prediction generated for a Student Snapshot.

A Prediction represents the AI model's assessment of a student's dropout risk based on academic and behavioural evidence.

Predictions are generated automatically and are never manually modified.

Whenever a new Student Snapshot is created, a new Prediction is generated.

---

# Aggregate Owner

AI Aggregate

---

# Template Type

Operational Entity

---

# Business Rules

- Every Prediction belongs to exactly one Student Snapshot.
- Every Prediction is generated by one AI Model Version.
- Every Student Snapshot can have only one latest Prediction.
- Predictions are read-only after generation.
- A new Student Snapshot always produces a new Prediction.

# Columns

| Column | Type | Nullable | Description |
|---------|------|----------|-------------|
| id | UUID v7 | ❌ | Primary Key |
| organization_id | UUID | ❌ | Organization |
| student_snapshot_id | UUID | ❌ | Student Snapshot |
| prediction_label | ENUM | ❌ | LOW, MEDIUM, HIGH |
| prediction_score | DECIMAL(5,2) | ❌ | Prediction Confidence (%) |
| explanation | TEXT | ✅ | AI Explanation |
| ai_model_version | VARCHAR(30) | ❌ | AI Model Version |
| generated_at | TIMESTAMP | ❌ | Prediction Timestamp |

---

# Business Constraints

- One Prediction belongs to one Student Snapshot.
- Predictions are immutable.
- Prediction Score must be between 0 and 100.
- Prediction Labels are generated only by the AI model.
- Predictions cannot be edited manually.

# Notes

Predictions represent AI-generated risk assessments.

Examples

```
Prediction Label

HIGH
```

```
Prediction Score

91.40%
```

```
Explanation

Attendance has declined over the last two imports.

Behaviour Summary indicates increased academic stress.

Assessment performance shows a downward trend.
```

Predictions never modify Academic data.

Predictions are consumed by the Counseling module for intervention planning.
