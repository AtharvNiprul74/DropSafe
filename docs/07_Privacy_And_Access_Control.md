# Purpose

This document defines how student privacy is protected and how access to sensitive information is controlled within DropSafe.

Privacy is a core principle of the platform.

The objective is to ensure that every user only accesses the information required for their responsibilities.

---

# Core Principles

## Principle 1

Student privacy takes precedence over operational convenience.

---

## Principle 2

Access follows the Principle of Least Privilege.

Every user receives only the minimum access necessary.

---

## Principle 3

AI never grants access.

AI only recommends actions.

---

## Principle 4

Every access request must be auditable.

---

## Principle 5

Sensitive information should be shared through summaries whenever possible instead of exposing raw data.

# Mentor Access

Mentors receive only the information required to support assigned students.

This includes:

- Student Profile (limited)
- Academic Summary
- Behaviour Summary
- Risk Trend
- Contributing Factors
- Previous Counseling History (assigned cases only)

Mentors do not receive institutional administrative data or raw student conversations.

Mentors never receive:

- Raw WhatsApp messages
- Student private conversations
- AI prompts
- Internal model outputs

---

# Teacher Access

Teachers may access

- Academic records
- Attendance
- Assessment results

Teachers cannot access

- Behaviour Summary
- Predictions
- Counseling Notes
- Chatbot Data

---

# Organization Admin

Organization Admin may

- Manage users
- Import academic data
- Approve mentor access
- View organization reports
- View prediction dashboards

Organization Admin cannot

- Read private chatbot conversations
- Modify AI-generated behaviour summaries

---

# Student Access

Students interact only through WhatsApp.

Students are not shown internal AI analysis.

Students do not receive:

- Risk Score
- Prediction History
- Behaviour Summary
- Internal AI Reasoning
- Mentor Recommendations

Students interact naturally with the chatbot without being labeled as "high risk" or "low risk".

Students may

- Chat with AI
- Receive support
- View counseling schedules (future)
- Participate in counseling

---

---

# Temporary Access

Mentor access is not permanent.

Access should be reviewed after:

- Counseling completed
- Student improved
- Student graduated
- Case closed

---

# Audit Requirements

Every sensitive action must be logged.

Examples

- Mentor Access Granted
- Mentor Access Revoked
- Prediction Viewed
- Counseling Created
- Academic Import
- User Login

---

# Privacy Rules

- Student conversations are never shared.
- Behaviour summaries replace raw conversations.
- AI recommendations remain internal.
- Every access requires authentication.
- Every access is logged.

---

# Data Retention

Academic Records

Retained according to organization policy.

---

Behaviour Summary

Historical summaries retained.

Never overwritten.

---

Prediction History

Retained for historical analysis.

---

Chatbot Conversations

Stored securely.

Never exposed to mentors.

Retention period configurable by organization.
